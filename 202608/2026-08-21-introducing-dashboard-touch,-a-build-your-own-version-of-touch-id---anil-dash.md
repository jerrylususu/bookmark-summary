## TL;DR
Anil Dash 因不想受苹果键盘束缚，基于 tinyTouch 开发开源项目 Dashboard Touch，用低成本指纹传感器和微控制器自制 USB 指纹认证装置，模拟键盘自动输入密码。密码与指纹均存本地，仅适合安全环境个人使用。他也分享了动手制作的乐趣，希望社区改进。

## Summary
作者 Anil Dash 一直想要一个独立于苹果键盘的 Touch ID 指纹认证方案，因为他日常使用的是机械键盘，不喜欢被苹果键盘束缚。他尝试过各种替代品，甚至有人拆解昂贵的苹果键盘只为了取出 Touch ID 传感器，但都没有完美解决。于是他基于 Zimeng Xiong 的 tinyTouch 项目进行了大量重构，发布了开源项目 Dashboard Touch。

这个项目让你用低成本的现成指纹传感器和一个小型微控制器，自己焊接、连接后通过 USB 插入 Mac。运行安装脚本后，用户会得到一个运行在 Mac 本地的网页界面，可以设置传感器环形灯的颜色、录入指纹等。日常使用中，只要 Mac 弹出密码输入框，你用手指在传感器上刷一下，设备就会模拟键盘自动帮你输入密码。从技术上说，这个装置实际上被识别成了一个键盘。

安全方面，你的密码只安全地存储在 Mac 上，指纹数据只存储在传感器本地，不会上传到互联网。唯一联网功能是一个手动点击才会运行的更新检查。作者也提醒，这适合物理环境安全、不会被人长时间 unsupervised 接触的个人使用场景，不适合保护银行金库级别的高价值目标。

文章后半部分，作者分享了他重新动手做东西的快乐：焊接、在木工房给传感器做外壳、剪辑介绍视频等。这个项目让他跳出舒适区，也让他找回了早期互联网那种普通人自己动手做有趣小玩意儿的氛围。他希望更多人能一起改进这个项目，并享受“触摸闪烁灯光”的乐趣。
