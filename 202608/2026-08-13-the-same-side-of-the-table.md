# The Same Side of the Table
- URL: https://staysaasy.com/the-same-side-of-the-table/
- Added At: 2026-08-13 14:26:55
- Tags: #read #people

## TL;DR
管理者在会议中须始终与下属同一立场，不当众指责、撇清或围攻。下属失误时，应接棒引导、暂停或共担责任，会后辅导；提前承诺救场能增强安全感。这是避免恐惧文化，也是管理者荣誉，真正支持是压力下不背弃。

## Summary
这篇文章围绕一个核心比喻展开：在谈判中，坐在桌子同一侧的人代表同一阵营；管理者与直接下属在任何会议中也必须始终坐在桌子的同一侧。这意味着下属的表现就是管理者的延伸，无论下属说错话、卡壳、被尖锐问题逼到墙角，还是搞砸了汇报，管理者都不能当场站到对立面去指责、撇清或加入围攻。

文章首先明确了管理者的基本立场。下属说了蠢话，你不能跟着嘲笑或补刀；下属一时语塞，你不能抱臂旁观；下属被难题困住，你更不能像审判者一样继续抛难题，而应把问题记下来，会后私下辅导；如果场面失控，你不能说“我不同意他/她的说法”来划清界限。唯一例外是极端情况，比如下属攻击他人或在桌上裸奔，那当然不需要一起发疯，但除此之外，原则不可动摇。

既然团队不可能永远完美，文章给出了几种“下属正在搞砸时”的正确处理方式。一是优雅地接过主导权，替下属把会议继续带下去，这会让双方都有点尴尬，但能维持进度；二是暂停这部分内容，请求稍后再议，避免当众处刑式的公开羞辱；三是明确说“我们还没准备好讨论这个”，然后把话题转为防守，自己承担所有权或责任；四是极少数情况下，如果下属明确违背了你事先的要求且表现极差，可以保持中立，既不攻击也不辩护，但前提是你已经准备很快解雇对方。

此外，管理者应该提前给团队一个明确承诺：如果会议变得激烈，我会帮忙引导。这种简单信号能提供很强的安全感。文章举了一个实际例子：作者曾安排一些中层成员向一位非常犀利、可能让人紧张的董事会成员汇报。他做了几件事：提供完整背景和对方履历；开两次准备会；说明哪些问题由自己回答、哪些由团队回答；自己了解足够多的主题内容，以便必要时独自接手；并告诉团队自己会作为“观察员”在会议中保持警觉，随时准备救场。

文章最后解释为什么要坚持这一原则。体育团队即使某个人明显失误，赛后发布会也会极力避免公开指责队友，因为他们知道指责既不能让自己免责，也会摧毁信任和未来的表现。从实用角度看，当众指责会彻底断送下属自我救赎的可能，并在团队中制造恐惧文化。从荣誉角度看，下属出错本来就反映管理者的失职，试图自保地划清界限并不聪明。坚持坐在同一侧，体现的是管理者的荣誉感，而优秀的人长期只会愿意与有荣誉感的人共事。

简言之，这篇文章是在提醒管理者：会议不是展示你比下属高明的场合，而是检验你能否真正承担团队责任的地方。真正的支持不是包庇，而是当场不背弃、事后去辅导；真正的管理不是表演权威，而是在压力下依然站在自己人身边。
