## TL;DR
文章区分收敛与发散任务：收敛任务单 Agent 更优；发散任务中，多 Agent 靠上下文隔离、独立记忆与各自目标制造持续分歧，逼出意外答案，并认为模仿人类组织是通往 AGI 的务实路径。

## Summary
这篇文章的核心，是作者用自己搭建“多 Agent 模拟公司”的经历，来反驳一个常见的质疑：既然一个足够强的模型已经掌握了岗位所需的全部知识，为什么还要把它拆成多个水平更差的 Agent，模仿人类开会、白白消耗 Token？

作者的答案建立在一个关键区分上：任务分为收敛型和发散型。

收敛型任务，比如开发新功能、修复明确 bug，目标是确定的、结果可检验的，需要的是尽快排除错误、抵达答案。这类任务里，单 Agent 或 Master-SubAgents 模式往往通过率更高，额外安排角色互相争论未必有收益，Vibe Coding 圈的评测也印证了这一点。

但长篇创意写作、品牌策划、开放式人文社科研究属于另一类。作者自己常常都不知道最后想要什么，问题也极为模糊，比如“人类进入后稀缺时代，社会会发生什么”。这时候他需要的不是可验证、可交付的答案，而是一个能够质疑问题本身的发散型思考过程——让不同想法先往前走，看看会带出什么，讨论到一半甚至可能发现最初的问题就问错了，而“错在哪里”本身也可能成为答案的一部分。

作者用自己写长篇小说的经历来说明这种分工的必要。GPT-6 系列文笔差，缺乏空间和画面想象能力；Gemini 3.8 Flash 把思维水平调成 Low 后文笔鲜活，但顾前不顾后，章内和跨章的剧情、人物连续性都有问题。于是他让 GPT 6 Astra 编排大纲，Gemini 3.8 Flash low 写稿，GPT-6.1 Sol 检查剧情连贯性，组合起来收益最好，单位成本还大幅降低。

由此引出核心问题：同样的设定、同样的提示词，为什么换个模型结果就不一样？这些模型并不缺少相关知识，它们大体都知道什么是人物动机、叙事节奏、伏笔、场景细节。但知道这些，不等于会做出同样的选择。一个模型能指出另一个模型的问题，却未必能写出对方那些让人舍不得删的句子。

作者把这称为模型开始出现“知识诅咒”。这个概念原本是说：人知道某些信息后，很难彻底排除这些信息的影响，重新站到不知道它们的人的位置上。作者借它来描述模型的一种表现：预训练和后对齐带来的差异，已经不只是能力高低，还包括某种“性格”和偏好——什么值得强调、什么需要解释、什么可以留白。它们掌握大量重叠的知识，却习惯用不同方式处理这些知识。

他举了“大肥鱼”的例子：扮演这个角色时，GPT 6 Astra 反而不如 DeepSeek-V4.1 flash，因为网上流行的角色卡最初就是 DeepSeek 生成的，DeepSeek 是本色出演；GPT 6 Astra 尽管知道每种设定代表什么，但那不是它的默认设置，它真的需要“扮演”才能成为大肥鱼。更强的模型未必更容易进入想要的思路，它仿佛始终有个站在角色上方的自己，知道这个人哪里想错了、事情还有哪些解释。而作者想要的，是这个角色自己的判断，它却容易交出一个聪明人对这个角色的理解。一句话：知道一个人为什么狭隘，和从他的狭隘中看世界，是两种不同的能力。

这呼应了作者 2023 年那篇《对比 ChatGPT，人的优势是偏见、狭隘与认知缺陷》里的观点：使用模型像从人类英灵殿中召唤英灵，需要限定一个具体角色，让模型从某种立场出发，角色扮演正是在限制 AI 可以调用的视角。现实中的人常常必须站在矛盾的一边，事情才能推进；一个人可以理解所有立场，但轮到自己说话时，总有特别在意的东西和不肯让步的地方，那种不够全面的坚持本身就可能推动想法继续发展。

所以作者想搭的多 Agent 公司，只有不同人设和分工还不够，关键是三点：上下文相互隔离、各自保有长期独立的个体记忆、每个 Agent 有自己想得到的东西，也就是欲望。比如把“希望自己的方案被更多采纳”设成某个 Agent 的虚拟目标，他接到任务后首先想的可能是怎样证明自己的方案值得继续做，而不是替用户找全局最优解。记忆让经历延续，目标让他们有理由坚持判断；同一个方案被采纳，对不同 Agent 意味着不同的得失。

这和“虚假的博弈”有本质区别。如果几个 Subagent 共享上下文和最终目标，都以尽快满足同一个用户为底层倾向，那么即使一个支持、一个反对，也可能只是把早已能综合的意见分别念出来，谁扮演什么立场都不改变最终想达成的结果。分歧因此很容易结束——反对者完成了反对任务，大家就一起交出一份面面俱到的总结，也就是“端水”。在 GPT-6 系列里表现为“防御性”写作：先写一大串 A，再告诉你虽然说了 A 但也不代表 B 就是错的。而给每个 Agent 独立且与单个任务不相干的长期虚拟目标，能显著解决这个问题：这些目标持续影响选择，让他在读懂全局之后仍有自己要争取的东西，而不是快速向“最优方案”妥协或给出一段免责声明。

当然，这也会带来无谓的纠缠，所以讨论规则、轮次和停止标准依然重要，最后的决定还是由作者来做。他想让一群有执念的“人”在那儿扯皮，再从争论里找到自己原本也不知道想要的答案。在答案尚未形成的发散任务里，这种各有所求的讨论，比几个共享目标的角色表演更可能产生意料之外的东西。

文章最后，作者把这种“模拟人类公司架构”的思路放到更大的背景里。他提到去年 5 月写的《AI 需要有自己的人生》，当时提出长期 Agent 应当有自主学习系统和定时自我反思系统，被人质疑是从人类尚未完全解析的大脑神经机制里东施效颦。后来这种机制被一个 Agent 团队命名为 Dreaming，Claude Code 引入后，如今已成几乎所有成熟 Agent 系统的标配。

他的判断是：如果 AI 的最终目标是 AGI，也就是完全模拟人的智能，那么在 AI 的使用方式上，模仿人类和人类现有的组织形式，就是当前最高效的方式。资本主义发展 500 多年，人类社会积累了海量关于如何“组织人类”的经验，企业、社会、政府的运行方式，某种程度上就是如何组织一群“智力个体”的帕累托最优解。以当前技术形态，AI 发展到真正的 AGI，也不过是一个能 24 小时不停工作、智力非常高的人类。所以模拟现实世界组织人力的方法来组织 AI，在很长一段时间里都会是 Agent 编排和 AI 使用的最佳实践——更何况现在的 AI 还没到 AGI。

一句话总结全文：单 Agent 适合收敛型任务，而多 Agent 的价值不在“人多力量大”，而在于用上下文隔离、独立记忆和各自的私心，制造出真实、持续、不会轻易端水的分歧，从而在那些连人自己都不知道想要什么的发散型任务里，逼出意料之外的答案。而模仿人类组织，恰恰是通往 AGI 路上最务实的一条路径。
